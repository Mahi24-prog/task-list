# Task List App

A simple zero-dependency (other than React UI libraries) Task List application built with React, TypeScript, and Vite.

## Features

- View all tasks, active tasks, or completed tasks.
- Add new tasks with title and description.
- Mark tasks as completed or incomplete.
- Delete tasks.
- View task details and edit them.

## Tech Stack

- **React** (v18)
- **TypeScript**
- **Vite**
- **Material UI** (MUI v5)
- **React Router** for navigation
- **React Query** for async state management

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Running Tests

To run the test suite:

```bash
npm run test
```
